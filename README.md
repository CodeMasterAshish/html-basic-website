# HTML Portfolio Website

A simple multi-page portfolio website built using only HTML. This project demonstrates the use of semantic HTML, navigation links, tables, forms, and proper page structure without any CSS or JavaScript.

## Live Demo

🔗 Add your GitHub Pages link here

## Features

* Multi-page website
* Home page
* Projects page
* Articles page
* Contact page
* Navigation between pages
* Contact form
* Semantic HTML structure
* No CSS or JavaScript

## Project Structure

```text
.
├── index.html
├── projects.html
├── articles.html
├── contact.html
└── README.md
```

## Pages

### Home

Displays personal information, projects, work experience, education, and reviews.

### Projects

Lists portfolio projects with links and descriptions.

### Articles

Contains articles and learning resources.

### Contact

Includes a contact form with fields for name, email, and message.
